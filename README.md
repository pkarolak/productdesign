# Product Designer Portfolio

A portfolio template for a product designer: four case studies at teaser depth, password-gated, built with Next.js and deployed on Vercel.

**Status:** in design (style direction selection). See [docs/progress.md](docs/progress.md).

Quick start, customization and deploy instructions are added once the app is scaffolded.
