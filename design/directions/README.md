# Style directions

Phase 0 concept rounds. Each round has its own README with the images and notes. The final pick is recorded in ADR 0002 (`docs/decisions/0002-style-direction.md`, written at `direction-lock`).

- [Round 1](round-1/README.md): A to E, all rejected.
- [Round 2](round-2/README.md): F to I, clean and modern with subtle gradients and isometric grids. G (Blueprint) was the favourite.
- [Round 3](round-3/README.md): Blueprint refined, with the pill nav from A, mixed asset types, and Lato plus a heading font. **Approved.** The teal accent was then replaced by Blueprint Cobalt ([../preview/accent.png](../preview/accent.png)).
- [Round 4](round-4-milonga/README.md): Milonga, a warm personal second theme (runner, climber, tango dancer and DJ). Rejected as too close to benshih.design.
- [Round 5](round-5/README.md): After dark, Race kit and Topo, each drawn from the designer's own world. Proposed.
- **Locked:** [../../DESIGN.md](../../DESIGN.md).
