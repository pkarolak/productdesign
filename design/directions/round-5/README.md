# Round 5: personal directions, away from benshih.design

Round 4 (Milonga) was rejected for being too close to [benshih.design](https://www.benshih.design/): cream paper, a soft chunky display face, handwritten notes, pastel tiles, tilted fanned cards and the "Hi, I'm" opener. Each direction here draws its look from the designer's own world instead. The app behaviours (command menu, sheets, working player, view transitions) carry over to any pick, since they are interaction patterns, not a visual style.

**Status:** proposed, awaiting a pick.

| Direction | Source world | Image |
| --- | --- | --- |
| After dark | A milonga DJ booth at 1am: warm near-black, one tungsten amber signal, condensed display type, widgets built like DJ hardware (deck, level meters) | [r5-afterdark-hero.jpg](r5-afterdark-hero.jpg) |
| Race kit | A running watch and race bib: cool white and graphite, safety orange, condensed italic display, case metrics as splits, an elevation profile | [r5-racekit-hero.jpg](r5-racekit-hero.jpg) |
| Topo | A climbing guidebook: chalk and granite, fine contour lines, a red route line with numbered pins, grade tags | [r5-topo-hero.jpg](r5-topo-hero.jpg) |

## Notes for the build

- Race kit: the comp sets the splits in a mono face; the build would use tabular figures in the sans, since mono fonts are off the table.
- Topo: the crag is a detailed illustration; the build would use a simpler hand-authored SVG line drawing, or a photo placeholder until a real crag drawing exists.
- After dark: the deck and meters map directly onto the Now playing widget, so it is the cheapest to build faithfully.
